# Flying_rabbit

앵그리버드 모작 — 새 대신 토끼를 새총으로 발사해서 구슬(돼지 역할)을 맞추는 물리 기반 퍼즐 게임입니다.

## 씬 구성

### MainMenu 씬
- **타이틀**: "Flying Rabbit" 로고 텍스트 (핑크색, 검은 아웃라인의 카툰 스타일)
- **게임 시작 / 설정 버튼**: 초록색 스타일 버튼, 그림자 효과 적용
- **설정 패널**: 사운드 On/Off 토글 (PlayerPrefs로 저장되어 재실행 시에도 유지), 닫기 버튼
- **토끼 미리보기**: 실제 게임에서 쓰이는 토끼 3종(흰색/회색/주황색)을 3D 모델로 배치해서 카메라를 정면으로 바라보게 함
- 밤하늘 스카이박스(Procedural Skybox 2.0 Lite - Night)로 배경 통일

### Round1 씬 (실제 플레이 씬)
- **새총(슬링샷)**: Wooden Slingshot 3D 모델 사용, 토끼가 고무줄 자리에 자연스럽게 걸쳐 앉은 모습
- **발사 메커니즘**: 마우스 드래그로 토끼를 당겼다 놓으면 포물선으로 발사 (뒤로만 당길 수 있고 항상 목표물 방향으로만 날아가도록 제한)
- **궤적 미리보기**: 드래그하는 동안 예상 낙하 경로를 흰색 선으로 실시간 표시
- **발사체**: 토끼 3마리(흰색 → 회색 → 주황색 순서로 자동 장전)
- **장애물**: 박스 + 구슬(초록색 공) 조합 3세트 배치
- **자동 소멸**: 토끼와 구슬 모두 바닥에 떨어지고 2초가 지나면 자동으로 사라짐
- **UI**: 좌측 상단에 남은 토끼 수, 우측 상단에 점수 표시
- **점수 규칙**: 구슬 하나를 떨어뜨릴 때마다 +10점
- **게임 종료 조건**:
  - 구슬을 모두 없애면 **Clear** 화면
  - 토끼를 다 썼는데 구슬이 남아있으면 **Fail** 화면
  - 두 경우 모두 "다시 시작" 버튼으로 스테이지를 재시작 가능

## 사용 에셋
- 3D 모델: 토끼 3종(Rabbit/Gray Rabbit/Orange Rabbit), Wooden Slingshot — 내장 텍스처(diffuse/normal) 추출 후 연결
- 스카이박스: AllSkyFree, Procedural Skybox 2.0 Lite
- 폰트: 맑은 고딕 기반 TMP 폰트 에셋(한글 지원)
